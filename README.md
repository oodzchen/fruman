# fruman

English | [中文](README.zh.md)

fruman is a browser-based 2D side-scrolling action game built with TypeScript. PixiJS handles rendering, Box2D WASM provides physics simulation, and the game logic runs in a Web Worker using an ECS architecture.

The project features real-time combat, weapons and skills, grappling, terrain interactions, lighting, and a day-night cycle. It also includes a built-in editor for creating maps and character bodies.

## Local Development

```bash
npm install
npm run dev
```
